I stumbled upon [Wampy](https://github.com/unknown321/wampy), a custom plugin that gives Sony Walkman players a retro cassette tape interface. After using it for a while, I found out Wampy supports custom cassette skins per album — but making one by hand is a pain: find the cover art, resize it, draw reel animations, convert formats. One skin is doable. A hundred? No thanks.

So I built CoolCassette. Plug your Walkman into your computer, and it reads the music on it, generates cassette skins based on each album's cover art, and installs them directly to the device. A few clicks and you're done. Don't like the result? Hit regenerate — it's a lottery!

## Before you start

### 1. ImageMagick

An image processing tool that CoolCassette uses to crop covers and composite tape images.

{{< tabgroup >}}
{{< tab name="macOS" >}}

If you have Homebrew installed, open Terminal and run:

```bash
brew install imagemagick
```

{{< /tab >}}
{{< tab name="Windows" >}}

Download the installer from the [ImageMagick website](https://imagemagick.org/script/download.php#windows). Make sure to check "Add to system PATH" during installation.

{{< /tab >}}
{{< /tabgroup >}}

### 2. AI API Key

Cassette images are generated by AI, so you'll need an API key.

Currently using the Gemini NanoBanana 2 model — about $0.05 per skin, very cheap. By default it goes through [OpenRouter](https://openrouter.ai). (Bad news: my key already got banned 😢)

The app reads the `OPENROUTER_API_KEY` environment variable by default. You can also create a config file at:

- **Windows**: `C:\Users\<YourUsername>\.coolcassette.json`
- **macOS**: `~/.coolcassette.json` or `/Users/<YourUsername>/.coolcassette.json`

Quick setup on macOS:

```sh
echo '{"api_key":"sk-or-...","provider":"openrouter"}' > ~/.coolcassette.json
```

Sign up at [OpenRouter](https://openrouter.ai), create a key (starts with `sk-or-`), and you're set.

## Three steps to get started

### Step 1: Connect your Walkman and configure directories

1. Connect your Walkman to your computer via USB
2. Open CoolCassette, click **Settings** in the top right
3. Configure the following:

| Setting | What to fill in |
|---------|----------------|
| **Music Directory** | The music folder on your Walkman, e.g. `E:\Music\`. You can also add your SD card's music folder. (On macOS it might be `/Volumes/WALKMAN/Music`) |
| **Wampy Directory** | The Wampy folder on your Walkman, usually `E:\wampy\` (On macOS it might be `/Volumes/WALKMAN/wampy`) |

> **How to find these?** After connecting your Walkman, open it in File Explorer (Windows) or Finder (macOS). You'll see `Music` and `wampy` folders. CoolCassette has a folder browser in the settings — just click to select. (Note: the Windows folder picker has some issues right now, so you may need to type the path manually, e.g. `E:\Music\`, `E:\wampy\`)

After configuring, click **Reload Library**. The app will scan the music on your Walkman and display your album list. (Tip: Use Sony's Music Center to import music — it organizes folders automatically. Note that CoolCassette groups albums by folder.)

And of course, after downloading new albums, you'll need to reload the library 🥹

### Step 2: Generate cassette skins

1. Find an album you want in the list, click to open it
2. Click **Generate Preview**
3. Wait 10–30 seconds while AI generates the cassette image from the album cover
4. Preview the result — including the tape shell and spinning reel animation

### Step 3: Publish to Walkman

Happy with the result? Click **Publish** and CoolCassette will install the skin directly to your Walkman.

Disconnect USB, open Wampy on your Walkman, play the album — and there's your custom cassette skin.

> Not satisfied with the result? Click **Generate Preview** again. AI produces different results each time — try a few times and you'll find one you like.

## FAQ

### Does it cost money to generate a skin?

Using the Gemini NanoBanana 2 model through OpenRouter, about $0.05 per skin. Very cheap.

### What audio formats are supported?

MP3, FLAC, WAV, M4A, M4B, AAC, MP4. Cover art is automatically extracted from file tags.

### Where does the cover art come from?

CoolCassette looks for covers in this order: `cover.jpg` (or png) in the album folder → embedded cover art in the audio file.

### Which Walkman models are supported?

Any Sony NW-series player with the [Wampy](https://github.com/unknown321/wampy) plugin installed.
